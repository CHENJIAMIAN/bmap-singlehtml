## 使用说明

1. 打开 `bmap.html`，把 `ak=YOUR_BAIDU_MAP_AK` 换成你自己的**浏览器端 AK**。
2. AK 到 [百度地图开放平台控制台](https://lbsyun.baidu.com/apiconsole/key) 申请，**务必配置 Referer 白名单**——不要留空，更不要填 `*`。
3. `mapv.html` 里同样需要换成你自己的 AK。

> 本仓库不再内置任何私有 AK。请勿把你申请的 AK 提交到公开仓库——浏览器端 AK 一旦公开，任何人都能拿它刷你的调用额度。
