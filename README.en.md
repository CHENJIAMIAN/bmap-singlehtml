# bmap-singlehtml

Pure HTML single-page examples for Baidu Maps and MapV

## Usage

1. Open `bmap.html` and replace `ak=YOUR_BAIDU_MAP_AK` with your own **browser-side AK**.
2. Apply for an AK in the [Baidu Map console](https://lbsyun.baidu.com/apiconsole/key) and **always configure a Referer whitelist** — never leave it empty or set it to `*`.
3. Do the same for the sample AK in `mapv.html`.

> This repository ships no private AK. Never commit your own AK to a public repository: once a browser-side AK is public, anyone can burn your quota with it.
